# the KJ Studio

작곡가이자 앱 개발자 Joon Kim의 개인 사이트.
누르면 소리가 나고 작업이 열리는 진입 화면을 가진다.

## 개발

```
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 프로덕션 빌드
```

설계 문서는 `docs/superpowers/specs/` 에 있다.

## 라이선스

코드는 MIT (`LICENSE`).
`public/images/` 이하의 사진, `src/works/` 의 글, 그리고 사이트에 쓰인
음원은 저작권자에게 권리가 있으며 MIT 범위에 포함되지 않는다.
