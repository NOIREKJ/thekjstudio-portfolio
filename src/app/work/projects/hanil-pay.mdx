## Overview

Hanil Pay는 Swift(iOS 네이티브)와 PWA(Progressive Web App) 기술을 결합한 결제 플랫폼입니다. iOS 앱과 웹 브라우저 어디서든 동일한 결제 경험을 제공하며, 빠르고 안전한 트랜잭션 처리를 목표로 설계되었습니다.

## Key Features

- **네이티브 iOS 앱**: Swift로 개발된 iOS 클라이언트로 부드러운 애니메이션과 네이티브 UI 제공
- **PWA 지원**: 별도 앱 설치 없이 웹 브라우저에서도 동일한 기능 사용 가능 — [POS 사이트 바로가기 →](https://hanilpay-app.vercel.app/)
- **간편 결제 플로우**: 최소한의 단계로 빠른 결제 완료
- **보안**: 결제 데이터 암호화 및 안전한 트랜잭션 처리

## Tech Stack

- **iOS**: Swift, SwiftUI
- **Web**: PWA (Progressive Web App)
- **Design**: 네이티브 iOS HIG 기반 UI/UX

## Challenges and Learnings

Swift 네이티브 앱과 PWA 두 플랫폼을 동시에 지원하면서 일관된 사용자 경험을 유지하는 것이 핵심 과제였습니다. 플랫폼별 특성을 살리면서도 동일한 결제 로직과 UX를 구현하기 위해 공통 설계 원칙을 수립하고 적용했습니다.
